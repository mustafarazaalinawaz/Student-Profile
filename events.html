Practice topics

Git and GitHub workshop

A checklist of skills to practise while working on this portfolio. These are learning topics, not scheduled events.

Workshop activities

Track and commit changes

Inspect git status, stage only intended files, review the staged diff, and create a clear commit.

Work with branches

Create a branch for a focused change, push it to GitHub, and merge it after checking the result.

Collaborate with pull requests

Share a branch for discussion and review before integrating changes into a project.

Keep practice safe

Check the current branch and working-tree status before changing history. Use a disposable practice branch for undo exercises, and never publish credentials or personal information that should remain private.
